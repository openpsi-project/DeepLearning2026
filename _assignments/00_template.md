Although this assignment is optional, we highly encourage you to complete it to receive early feedback. It is an excellent opportunity to ensure you are on the right track and fully prepared for the upcoming graded milestones.

Please follow these steps to submit your assignment:

1.  **Download the Template:**
    Start by downloading the LaTeX template:
    - [Submission Template](../static_files/assignments/submission_template.zip)

2.  **Prepare Your Solution:**
    - Write your solutions in `main.tex`.
    - Compile the file to generate `main.pdf`.

3.  **Package Your Files:**
    Create a single zip file named `submission.zip` containing both your source code and the compiled PDF. The structure must look like this:
    ```text
    submission.zip
    ├── main.tex
    └── main.pdf
    ```

4.  **Submit:**
    Upload your `submission.zip` file to the Web Learning portal:
    - [Web Learning](https://learn.tsinghua.edu.cn/)
